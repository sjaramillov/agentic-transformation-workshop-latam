# Aviso de alcance y atribución

## Material propio

La guía resumida en español y los cinco diagramas de `diagramas/` son contribuciones originales de este repositorio y están bajo MIT.

## AWS y Workshop Studio

Los nombres AWS, AWS Transform, Workshop Studio, TravelCorp, los contenidos del taller, sus ejemplos de código y las imágenes enlazadas pertenecen a sus respectivos titulares. Este repositorio describe el taller con fines informativos y enlaza sus fuentes; no afirma que AWS respalde esta guía.

El paquete de Workshop Studio de la captura del 15 de octubre de 2026 permanece en la carpeta local del autor y no se publica aquí. No se encontró una licencia de redistribución para el código de ejemplo TravelCorp, así que la licencia MIT de este repositorio no se aplica a ese paquete.

El repositorio [AWS Samples: Portfolio Analysis Orchestrator](https://github.com/aws-samples/sample-agentic-readiness-analysis-orchestrator) es un proyecto separado de AWS. Consulta su archivo `LICENSE` y los avisos del upstream; este repositorio enlaza a la versión pública y no incluye una copia anidada.
