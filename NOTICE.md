# Autoría y referencias

El código de `booking_lab/`, las herramientas de `scripts/`, las pruebas de `tests/`, la guía en español y los diagramas son contribuciones originales distribuidas bajo [MIT](LICENSE). La réplica de reservas se escribió para este repositorio y no necesita el paquete del evento.

AWS, AWS Transform y Workshop Studio son nombres de sus respectivos titulares. Este proyecto independiente usa el taller como referencia educativa y enlaza sus fuentes. No afirma respaldo de AWS.

PostgreSQL, Python y Psycopg se instalan como dependencias externas y conservan sus propias licencias. Consulta las licencias de [Psycopg](https://github.com/psycopg/psycopg/blob/master/LICENSE.txt), [PostgreSQL](https://www.postgresql.org/about/licence/) y [Python](https://docs.python.org/3/license.html). Las imágenes oficiales contienen sus avisos y componentes. La licencia MIT de este código no modifica esas licencias.

El repositorio [AWS Samples: Portfolio Analysis Orchestrator](https://github.com/aws-samples/sample-agentic-readiness-analysis-orchestrator) es un proyecto separado; su licencia y avisos se consultan en el upstream.

Los archivos privados e informes históricos del evento se conservan para trazabilidad y no son necesarios para ejecutar la réplica MIT. No se incorporó código TravelCorp al nuevo servicio. Los contenidos externos enlazados mantienen sus términos y atribuciones.
