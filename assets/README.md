# Diagramas del módulo J

La sección final del taller enlaza cinco diagramas para presentar el modelo operativo. Durante la captura, sus enlaces abrieron una página de Workshop Studio con error “Page not found”; por eso este directorio no incluye PNG originales. Los títulos, rutas y conceptos del texto de la página quedan anotados aquí.

| Recurso enlazado | Idea que muestra |
| --- | --- |
| [Operating model layers](https://catalog.us-east-1.prod.workshops.aws/event/dashboard/en-US/workshop/static/images/operating-model/operating-model-layers.png) | AWS Transform ejecuta análisis y remediación; la organización proporciona el catálogo de TD y la plataforma; distintos equipos priorizan, revisan, integran y operan el cambio. |
| [Operating model journey](https://catalog.us-east-1.prod.workshops.aws/event/dashboard/en-US/workshop/static/images/operating-model/operating-model-journey.png) | Un servicio recorre el camino desde el estado actual, con un agente bloqueado, hasta una golden path que le permite operar. |
| [Platform dependency flow](https://catalog.us-east-1.prod.workshops.aws/event/dashboard/en-US/workshop/static/images/operating-model/platform-dependency-flow.png) | Antes de elegir una TD, confirmar que existe y está operada la plataforma destino; luego revisar, aprobar, integrar, desplegar y volver a medir. |
| [Platform artifact ladder](https://catalog.us-east-1.prod.workshops.aws/event/dashboard/en-US/workshop/static/images/operating-model/platform-artifact-ladder.png) | Una TD reúne artefactos que un equipo suele adoptar por separado —runtime, IaC, plantillas, pipeline e identidad— en una instrucción revisable. |
| [Repository topology](https://catalog.us-east-1.prod.workshops.aws/event/dashboard/en-US/workshop/static/images/operating-model/repo-topology.png) | IaC junto con el código permite una TD en un repositorio; IaC separado requiere coordinar cambios en varios repositorios y ordenar transiciones seguras. |

Las rutas se conservaron desde la propia página del evento; si el evento vuelve a estar disponible, abrir los enlaces desde la sección “What you accomplished” del módulo J puede dar acceso al archivo correcto.
